请生成一个单文件 `index.html` 的旅行手册网页，主题是“巴黎 + 南法旅行计划”，语言为简体中文，使用原生 HTML + CSS + JavaScript，不要拆分文件，不依赖框架，不要部署说明。

目标：
- 做成高质感、信息密度高、适合旅行前查看和旅途中随时编辑的单页网页
- 页面兼顾桌面端和移动端
- 所有数据默认内置，并支持用户本地编辑后持久保存
- 使用 `localStorage` 保存结构化内容
- 附件可使用 IndexedDB / File API 等浏览器本地方案保存和查看

页面结构：
1. 总览模块
2. VOUCHERS（凭证）
3. TRANSIT（交通）
4. 费用与通票建议
5. CHECKS（出发前确认）
6. TIMELINE（逐日安排）
7. MAPVIEW（每日地图）
8. 左侧书签目录

核心要求：
- 左侧有始终可见的书签目录，支持模块 / 城市 / day 多级跳转
- 当前滚动位置对应目录高亮
- 目录过长时可滚动
- 页面整体排版紧凑，避免空白浪费
- 模块标题保持单行，不换行
- NOW FOCUS、TRIP ALERTS、CHECKS、MAPS 在总览中上下排列
- NOW FOCUS 要和逐日安排联动同步
- 顶部路径只保留机场名（中文）、游览城市名、车站名

编辑能力：
- VOUCHERS / TRANSIT / CHECKS / TIMELINE / MAPVIEW 都要支持编辑模式
- 编辑模式下支持新增、删除、修改、拖拽排序
- 文本点击即可原位编辑
- 新增后生成与当前模块结构一致的空白项
- 删除按钮小而简洁
- 新增按钮放在模块顶部
- 所有适合排序的内容尽量支持拖拽排序

VOUCHERS：
- 展示酒店、火车票、机票、预订信息
- 每个项目支持编辑、删除、排序、上传附件、打开附件、替换附件
- “机票行程”和“具体行程”支持点击直接修改
- 附件按钮放在项目底部，界面简洁

TRANSIT：
- 展示跨城交通、日期、事件、状态、金额、建议
- 支持编辑、删除、排序、上传附件
- “已出票、金额、待补”等状态放到日期和事件下方展示
- 金额不要因为排版而断开换行
- 费用和建议可直接修改

CHECKS：
- 作为出发前确认清单
- 每项支持点击文本编辑、删除、排序、新增
- 每项下方支持备注输入，并可修改删除
- 交互风格和 VOUCHERS / TRANSIT 一致

TIMELINE：
- 按真实日期展示，不使用 day0/day1 这种写法
- 逐日安排支持城市分组，如巴黎、南法
- 每个城市下面显示 day 次级标签
- 支持新增日期、删除日期、调整日期顺序
- 新增日期时可以选择所属城市并指定具体日期
- 排序后自动同步 day 顺序与 MAPVIEW
- 每个 day 下的事件支持编辑、新增、删除、排序
- 事件标签、meta、气泡栏内容也支持编辑、删除、新增、排序

MAPVIEW：
- 每天都要有对应地图卡片
- 地图标出当天全部目的地
- 点位尽量完整展示，避免大量重叠
- 地图自动调整视野以清晰展示所有点位
- 点位显示顺序编号
- 每个 day 下方横向展示当天导航入口
- 地图中的地点支持新增、删除、修改、排序
- MAPVIEW 与 TIMELINE 数据联动
- 如果 day 顺序变化，地图同步更新
- 提供“打开 Google Maps 路线”按钮
- 若无法稳定内嵌 Google Maps，则优先使用自绘地图 / SVG + Google Maps 外链
- 昂蒂布当天出发点使用“昂蒂布住所”

附件能力：
- VOUCHERS、TRANSIT、CHECKS、费用模块支持上传多个附件
- 支持打开、替换、删除、重命名
- 附件区尽量紧凑，不占过多空间

视觉要求：
- 风格像旅行计划板 + 法式手册，不像后台系统
- 有设计感，但不过度装饰
- 卡片、边框、阴影、色彩、字体都要精致
- 桌面端使用左侧目录 + 右侧内容布局
- 移动端自动改单栏

默认内容：
- 内置完整的巴黎四天三晚 + 南法数日旅行计划
- 包含酒店、火车、机票、逐日行程、地图点位、费用建议、检查项、总览路径等
- 页面打开后应直接可用并可继续编辑

输出要求：
- 只输出完整 `index.html`
- 不要解释
- 不要伪代码
- 不要部署内容
